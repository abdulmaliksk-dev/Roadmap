# AI Software Engineer — 2027 Battle Plan by Malik

A static, GitHub Pages-ready roadmap for students targeting AI + Backend + Cloud.

## v2
- Dewaskar-inspired information architecture, not a copy
- Persistent sidebar with 64-week jump navigation
- Local progress with week shipping + phase completion
- Progress backup/import
- Search (Ctrl/Cmd + K)
- Responsive desktop/tablet/mobile layout
- Core / Supporting / Awareness scope discipline
- 11 phases / 64 weeks

## Deploy
Upload the contents of this folder to a GitHub repository and enable GitHub Pages from the `main` branch root.


## v3 visual/content update

- Phase pages now include a curated **Resources for this phase** section below the weekly plan.
- Resources are grouped by week range and tagged PRIMARY / PRACTICE / REFERENCE / INTERVIEW / JUST-IN-TIME.
- Added stronger card/table borders, larger body typography, wider content geometry, and a wider right rail to prevent cramped wrapping.
- Improved week cards, phase hero, progress bars, and table readability.
- Resource links open in a new tab and are maintained in `assets/js/resources.js`.
- Progress tracking remains localStorage-based and unchanged.
